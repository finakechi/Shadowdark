# Shadowdark
My Shadowdark Campaign and information.

A working project for learning Shadowdark, preparing a one-shot or short campaign, and testing original homebrew.

## Start here

1. Read [PROJECT_STATUS.md](PROJECT_STATUS.md) for current work and next actions.
2. Use the [official resource catalog](docs/research/official-resources.md) to locate materials.
3. Read the [baseline rules and design report](docs/rules/rules-reference.md).
4. Answer the [campaign setup questions](docs/decisions/open-questions.md).
5. Follow the [session preparation checklist](docs/campaign/session-preparation.md).

## Development workflow

Read status and decisions at the beginning of each work session. Research before changing rules; label published mechanics, creator commentary and our interpretations separately. Use [templates](templates/) for changes and session records. Only Noah can approve campaign rules as Accepted; proposals are not canon.

Keep purchases, private player information and unreleased GM secrets out of this public repository. Link to commercial resources instead of uploading their contents.
