## Simple conventions

- Use lowercase hyphenated Markdown filenames and relative repository links.
- Use SD-### for decisions, HB-### for homebrew proposals, and YYYY-MM-DD for dated sessions.
- Keep each rule in one authoritative proposal file; registers and status link to it.
- Research entries have stable R### IDs, source URL, verification date and acquisition status.
- In Drive, preserve publisher filenames; record actual printed/PDF revision after acquisition. Do not infer revisions from shop dates.
- Keep original editable handout text in GitHub and export files in Drive; link the two.
- Substantial changes to existing work should use a branch and pull request. Routine additive foundation work is authorized directly.
- Do not delete, replace important work, publish personal information or change access without Noah's approval.
- Do not upload official PDFs to this public repository, even when free. Public homebrew should use original wording and source references. Consult the publisher's current creator terms before releasing a derived product.
